# Intelligent Network Load Balancer (Day 1 starter)

## Requirements
- JDK 17
- Maven 3.8+ (or use the Maven wrapper generated by your IDE)
- IntelliJ IDEA or VS Code

## Run
1. Open this folder as a Maven project.
2. Run `LoadBalancerApplication.java`.
3. The load balancer runs on `http://localhost:8080`.
4. Three lightweight backend HTTP servers start on ports 8081, 8082, and 8083.

## Test
Open this endpoint repeatedly:
`http://localhost:8080/api/lb/hello`

Responses should rotate among Backend-1, Backend-2, and Backend-3.

Check server counts:
`http://localhost:8080/api/lb/servers`

## Day 1 scope
- Multiple backend servers
- HTTP request forwarding
- Round Robin routing
- Per-backend request counters
- Basic unavailable-backend handling

Note: This is an educational local prototype, not a production-ready load balancer. The backend simulator uses Java's built-in HttpServer. Day 2 can replace it with separate Spring Boot services and add proper health checks, least-connections, and recovery.
